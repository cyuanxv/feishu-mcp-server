## 仓库设置清单

1. 使用全新私有仓库，只上传审核后的干净源码，不复用旧提交历史。
2. 在仓库首页 About 设置上述简介与 Topics。没有独立公开产品主页时留空 Website，不填写私有服务地址。
3. 在 Settings → General → Social preview 上传 JPEG 封面。README 配图不会自动设置社交分享封面。
4. 重新打开仓库检查简介、Topics 和封面保存结果。只有用户明确同意后才改为公开。

JSON 配置见 `github-metadata.json`；它是配置清单，GitHub 不会自动读取并应用。私有状态下不会获得公开发现流量，不保证搜索排名。
